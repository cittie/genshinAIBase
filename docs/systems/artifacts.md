# 圣遗物系统

> 圣遗物的部位、主副词条规则、强化机制与套装机制。
> 机读数值：`data/artifacts/`

---

## 1. 五个部位

| 顺序 | 部位 | 字段值 `slot` | 固定主词条 |
|---|---|---|---|
| 1 | 生之花 | `flower` | 生命值（固定值） |
| 2 | 死之羽 | `plume` | 攻击力（固定值） |
| 3 | 时之沙 | `sands` | 可变（见 §2） |
| 4 | 空之杯 | `goblet` | 可变 |
| 5 | 理之冠 | `circlet` | 可变 |

- 一个角色最多装备 5 件，**每个部位 1 件**，不能重复。
- 生之花与死之羽的**主词条固定**，因此这两件的选择只看套装与副词条。

## 2. 主词条（Main Stat）

### 2.1 各部位可选主词条

| 部位 | 可选主词条 |
|---|---|
| 生之花 | 生命值（固定） |
| 死之羽 | 攻击力（固定） |
| 时之沙 | 攻击力% / 生命值% / 防御力% / 元素充能效率% / 元素精通 |
| 空之杯 | 元素伤害加成%（7 种元素）/ 物理伤害加成% / 攻击力% / 生命值% / 防御力% / 元素精通 |
| 理之冠 | 暴击率% / 暴击伤害% / 攻击力% / 生命值% / 防御力% / 元素精通 / 治疗加成% |

- **同一个部位只能有一个主词条**。
- 主词条数值随圣遗物等级提升（每级增长固定量），满级值取决于稀有度与词条类型。
- ⚠️ 各主词条的**满级具体数值档位待核实**，占位表：[`data/artifacts/artifact_main_stats.csv`](../../data/artifacts/artifact_main_stats.csv)。

### 2.2 主词条与副词条互斥

**副词条不会与主词条相同。** 例如时之沙主词条选了「攻击力%」，则副词条中不会出现「攻击力%」。

## 3. 副词条（Substat）

### 3.1 副词条池

固定生命值、固定攻击力、固定防御力、生命值%、攻击力%、防御力%、
元素精通、元素充能效率%、暴击率%、暴击伤害%。

- **同一件圣遗物的副词条不重复**（每个词条最多出现一次，但可被多次强化）。
- 副词条从池中随机抽取，数值从**档位**中随机取值（因此同名副词条数值有高低之分）。

### 3.2 初始副词条数量

| 稀有度 | 初始副词条数 | 等级上限 |
|---|---|---|
| 5★ | 3 或 4 条 | +20 |
| 4★ | 2 或 3 条 | +16 |
| 3★ | 1 或 2 条 | +12 |
| 2★ | 1 条 | +8 |
| 1★ | 0 条 | +4 |

> 5★ 初始 3 条时，**第 1 次强化（+4）会新增第 4 条副词条**，之后才强化已有词条。
> 因此 5★ 圣遗物总共获得 **5 次**副词条成长（新增 1 次 + 强化 4 次，或强化 5 次）。

### 3.3 强化机制

- 圣遗物每提升 **4 级**获得一次副词条成长：`+4 / +8 / +12 / +16 / +20`。
- 每次成长在**已有的副词条中随机挑一条**使其数值增加一个档位。
- 成长结果**完全随机**，不可控 —— 这是「毕业」难度的根源。

### 3.4 有效词条数（评估口径）

评估一件圣遗物质量的通用方法：**统计落在角色有效词条上的强化次数**。

```
有效词条数 = Σ(每个副词条的强化次数 × 该词条对该角色是否有效)
```

例：对依赖双爆的角色，「暴击率 +2 次、暴击伤害 +2 次、攻击力% +1 次」= 5 个有效词条（满分档）。
- 通常 **4 个以上有效词条**算良好，**5 个**接近毕业。
- 有效词条的判定随角色而变（吃精通/吃生命/吃充能的角色标准不同）。

> 词条有效性判定规则见 [`rules/stat-priority.md`](../../rules/stat-priority.md)（待补）。

## 4. 套装机制

- 每件圣遗物属于某**套装**（`set_id`）。
- 同一套装装备 **2 件**触发 2 件套效果，**4 件**触发 4 件套效果。
- 常见搭配：
  - **4 + 1**：4 件套效果 + 1 件散件（该件只看副词条）
  - **2 + 2**：两套 2 件套效果叠加（如 攻击力% + 元素伤害加成%）
  - **2 + 1 + 1 + 1**：不推荐，除非散件副词条极强
- 套装效果与词条无关，即使散件也计入件数。

### 数据表结构

| 文件 | 内容 |
|---|---|
| [`artifact_sets.csv`](../../data/artifacts/artifact_sets.csv) | 套装主表（名称、稀有度、2 件套类型与数值） |
| [`artifact_set_bonuses.csv`](../../data/artifacts/artifact_set_bonuses.csv) | **长表**：一个效果一行，含 4 件套的触发条件、持续、叠层 |
| [`artifact_main_stats.csv`](../../data/artifacts/artifact_main_stats.csv) | 各部位可选主词条与满级数值 |

> 4 件套效果常带**条件、持续、叠层上限**，因此用长表而非单列文本，便于 AI 过滤。

## 5. 获取途径

| 途径 | 说明 |
|---|---|
| 圣遗物秘境 | 消耗原粹树脂，产出指定套装 |
| 深境螺旋 / 终局玩法 | 产出与奖励 |
| 大世界敌人掉落 | 随机套装与部位 |
| 合成台「还圣奥迹」 | 用已有圣遗物兑换指定套装 |
| 活动 / 任务奖励 | 限定获取 |

> 各套装的获取途径需逐套装录入 `artifact_sets.csv`（字段 `source_domain`，可后续追加）。
