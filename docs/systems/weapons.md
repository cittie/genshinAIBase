# 武器系统

> 武器类型、稀有度、基础攻击力档位与精炼机制。
> 机读数值：[`data/weapons/weapons.csv`](../../data/weapons/weapons.csv)

---

## 1. 武器类型（5 种）

| 类型 | 字段值 `weapon_type` | 使用者 |
|---|---|---|
| 单手剑 | `sword` | 单手剑角色 |
| 双手剑 | `claymore` | 双手剑角色 |
| 长柄武器 | `polearm` | 长柄武器角色 |
| 法器 | `catalyst` | 法器角色 |
| 弓 | `bow` | 弓角色 |

**硬约束**：角色只能装备与其 `weapon_type` 一致的武器。这是武器筛选的第一道过滤条件。

---

## 2. 武器构成

每把武器由四部分组成：

```
武器 = 基础攻击力（随等级成长）
     + 副属性（类型固定，数值随等级成长）
     + 武器被动（随精炼等级提升）
     + 稀有度（决定成长上限）
```

### 2.1 基础攻击力

- 随武器等级与突破阶段提升，**只受等级影响**，与精炼无关。
- 满级（90 级）基础攻击力在 5★ 武器中分为若干**档位**（常见约 542 / 608 / 674 / 741 四档）。
- **规律**：基础攻击力低的武器，其副属性或被动通常更强（设计上的补偿）。
- ⚠️ 具体档位数值待逐件核实录入，`data/weapons/weapons.csv` 的 `base_atk_lv90` 列。

### 2.2 副属性（Sub Stat）

- 副属性的**类型固定**（同一种武器永远是同一个副属性），数值随等级成长。
- 常见副属性类型：
  - 攻击力% / 生命值% / 防御力%
  - 暴击率% / 暴击伤害%
  - 元素充能效率%
  - 元素精通
  - 物理伤害加成%
- 少数武器**没有副属性**（副属性为空）。
- ⚠️ 满级副属性数值待核实，`data/weapons/weapons.csv` 的 `sub_stat_value_lv90` 列。

### 2.3 武器被动

- 精炼等级 **R1 ~ R5**，由消耗同名武器提升。
- 被动通常包含：属性提升、条件触发增益、冷却时间、叠层上限。
- **精炼提升的是被动的数值或触发效率**，不改变基础攻击力与副属性。

> 因此：`R1` 与 `R5` 的武器强度差异**只体现在被动上**。
> 评估武器时必须区分精炼等级，AI 输出时不得混用。

## 3. 稀有度与成长

| 稀有度 | 等级上限 | 初始等级 | 说明 |
|---|---|---|---|
| 5★ | 90 | 1 | 成长上限最高，通常有独特被动 |
| 4★ | 90 | 1 | 主流过渡与平替选择 |
| 3★ | 70 | 1 | 前期过渡，少数有特殊价值 |
| 2★ | 70 | 1 | 材料 |
| 1★ | 70 | 1 | 材料 |

- 5★ 武器的等级上限与 4★ 同为 90，差别在**基础攻击力档位与副属性数值**。
- 部分 3★ 武器因被动特殊（如提供充能或精通）在特定配装中仍有价值。

## 4. 武器评估的关键变量

评估一把武器是否适合某角色时，需要同时考虑：

| 变量 | 说明 |
|---|---|
| `weapon_type` 匹配 | 硬约束，先过滤 |
| 基础攻击力 | 影响攻击力%词条收益（见 [stats-and-scaling.md](../mechanics/stats-and-scaling.md#21-攻击力)） |
| 副属性类型 | 是否落在该角色的**有效词条**上 |
| 被动触发条件 | 角色能否稳定触发（站场时间、元素类型、暴击与否） |
| 被动是否吃精炼 | R1 → R5 提升幅度 |
| 充能缺口 | 是否填补或加剧 ER 缺口（见 [energy-and-rotation.md](../mechanics/energy-and-rotation.md)） |
| 精炼成本 | 四星容易 R5，五星专武通常只能 R1 |

**常见误区**：

- 只看基础攻击力，忽略副属性适配度。
- 忽略被动触发条件（如「重击命中后」但角色不常用重击）。
- 用 R5 四星与 R1 五星对比时不声明精炼等级。

## 5. 数据缺失说明

本仓库**尚未录入**：

- 全部武器的基础攻击力与副属性数值（`weapons.csv` 仅有表头）
- 武器被动文本与各精炼等级数值（`weapon_refinements.csv` 待建）
- 武器的获取途径

> AI 使用要求：在数值补齐前，只能给出**方法论与结构性**结论
> （如「优先匹配副属性」「R5 四星与 R1 五星需分别评估」），
> **不得给出具体武器的具体数值或强度排名**。
