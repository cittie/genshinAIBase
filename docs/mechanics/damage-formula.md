# 伤害计算公式

> 适用范围：原神战斗系统的伤害计算。所有公式用于**单次伤害**，多段伤害需逐段计算后求和。
> 版本：通用（公式结构长期稳定）｜最后核对：2026-10-02

---

## 1. 总公式

一次伤害由若干**独立乘区**相乘。核心原则：**同乘区内相加，跨乘区相乘**。

```
最终伤害 = 基础伤害
         × 伤害加成区
         × 暴击区
         × 防御区
         × 抗性区
         × 增幅反应区          （仅蒸发 / 融化）
         × 独立加成区          （特殊套装 / 天赋，若有）
```

剧变反应（超载、感电等）走另一套公式，见 [reactions.md](reactions.md#3-剧变反应)。

---

## 2. 各乘区定义

### 2.1 基础伤害

```
基础伤害 = 技能倍率 × 面板属性
```

`面板属性` 由天赋描述决定，取**攻击力 / 生命值上限 / 防御力**三者之一（少数取多种）。

面板属性构成见 [stats-and-scaling.md](stats-and-scaling.md)。

- 技能倍率随天赋等级提升，逐级数值见 `data/characters/`（待补）。
- 一个技能的多段伤害各自拥有独立倍率，也各自独立走完整公式。

### 2.2 伤害加成区

```
伤害加成区 = 1 + 元素伤害加成 + 伤害类型加成 + 全伤害加成
```

- **元素伤害加成**：火/水/雷/冰/风/岩/草/物理 伤害加成（`elemental_dmg_pct` / `physical_dmg_pct`）。
- **伤害类型加成**：普通攻击 / 重击 / 下落攻击 / 元素战技 / 元素爆发 伤害加成。
- **全伤害加成**：对所有伤害生效的加成。
- ⚠️ **同类相加，跨类也相加** —— 上述三项都在**同一个乘区**内累加。
  例：火元素伤害加成 46.6% 与「焰硝众座」4 件套的重击伤害加成，直接相加。
- 判定的关键：该加成是否作用于**当前伤害的元素与类型**。不匹配则不计入。

### 2.3 暴击区

```
暴击时：暴击区 = 1 + 暴击伤害
未暴击：暴击区 = 1
```

伤害期望（用于配装比较，推荐使用）：

```
期望暴击区 = 1 + min(暴击率, 1) × 暴击伤害
```

- 暴击率超过 100% 的部分**无收益**。
- 暴击率与暴击伤害的**最优配比**约为 `暴击率 : 暴击伤害 = 1 : 2`
  （在总词条数固定的前提下，即 100% 暴击率 / 200% 暴击伤害的方向）。
- 比较两套配装时**一律用期望值**，不要用「暴击后大数字」比较。

### 2.4 防御区

```
防御区 = (角色等级 + 100)
       / [ (角色等级 + 100) + (敌人等级 + 100) × (1 - 防御力降低) × (1 - 无视防御力) ]
```

- `防御力降低`（减防）与 `无视防御力` 是**两个独立乘算因子**，不是相加。
- 角色与敌人**同等级**时，防御区 ≈ 0.5（90 级对 90 级）。
- 敌人等级越高，防御区越小，伤害越低。
- 大多数**剧变反应不吃防御区**。

### 2.5 抗性区

```
若 抗性 < 0        : 抗性区 = 1 - 抗性 / 2
若 0 ≤ 抗性 < 75%  : 抗性区 = 1 - 抗性
若 抗性 ≥ 75%      : 抗性区 = 1 / (4 × 抗性 + 1)
```

- 抗性为**负值**时收益减半（如 -40% 抗性 → 抗性区 1.2，而非 1.4）。
- 抗性 ≥ 75% 后收益急剧衰减，减抗收益极高。
- 抗性下限通常为 -100%。
- 各敌人抗性见 `data/enemies/enemy_resistance.csv`。

### 2.6 增幅反应区

仅**蒸发**与**融化**有此乘区：

```
最终伤害 = 原伤害 × 反应倍率 × (1 + 2.78 × 元素精通 / (元素精通 + 1400))
```

反应倍率见 [reactions.md](reactions.md#2-增幅反应)。

### 2.7 独立加成区

部分套装效果、天赋、武器被动提供**独立乘区**（不与伤害加成区相加），
例如「如雷的盛怒」4 件套对剧变反应的伤害提升。判定规则：

- 描述为「造成的伤害提高 X%」且被广泛验证为独立乘区 → 单独相乘。
- 描述为「X 伤害加成」 → 归入**伤害加成区**（相加）。
- 存在争议的条目：在 `data/` 中标注 `?`，不要默认当作独立乘区。

## 3. 期望伤害与 DPS 计算

配装比较（圣遗物 / 武器）的标准口径：

```
单次期望 = 基础伤害 × 伤害加成区 × (1 + min(暴击率,1) × 暴击伤害) × 防御区 × 抗性区 × 增幅反应区

循环期望 DPS = Σ(各段技能期望伤害) / 循环时长（秒）
```

**计算时必须固定的变量**（否则结论不可比）：

| 变量 | 说明 |
|---|---|
| 角色等级 / 天赋等级 | 默认 90 级 / 天赋 9-9-9，除非另有说明 |
| 敌人等级与抗性 | 默认 90 级、10% 抗性（若适用） |
| 队伍 buff | 明确列出，或声明「无队友」 |
| 循环轴 | 输出轴时长与技能顺序 |
| 是否计入暴击 | 一律用期望值 |
