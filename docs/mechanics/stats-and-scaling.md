> 机读数值：`data/characters/characters.csv`、`data/weapons/weapons.csv`

| 属性 | 字段名 | 基础值 | 单位约定 | 备注 |
|---|---|---|---|---|

| 元素充能效率 | `energy_recharge_pct` | **100** | % | |

## 2. 面板属性计算公式

### 2.1 攻击力

```
面板攻击力 = (角色基础攻击力 + 武器基础攻击力) × (1 + 攻击力百分比总和) + 固定攻击力总和
```

**关键点**：攻击力百分比只作用于**基础攻击力**（角色 + 武器），**不作用于**固定攻击力加成。

推论（重要，常用于武器选择）：

- 角色基础攻击力越高，攻击力百分比词条收益越大。
- 双爆类词条不参与此公式，是独立乘区（见 [damage-formula.md](damage-formula.md#23-暴击区)）。

### 2.2 生命值上限

```
面板生命值 = 角色基础生命值 × (1 + 生命值百分比总和) + 固定生命值总和
```

> 武器不提供基础生命值，因此生命值百分比词条只吃**角色自身基础生命值**。

### 2.3 防御力

```
面板防御力 = 角色基础防御力 × (1 + 防御力百分比总和) + 固定防御力总和
```

## 3. 基础值与成长

### 3.1 角色

- 每个角色有固定的**基础生命值 / 基础攻击力 / 基础防御力**，随等级与突破阶段提升。
- 角色等级上限：**90**（80 级后需突破）。
- 角色等级影响：基础属性、剧变反应等级系数、防御区（见 [damage-formula.md](damage-formula.md#24-防御区)）。
- **突破加成属性**：角色每次突破获得一项固定加成（如暴击伤害、攻击力%、元素精通、元素充能效率、元素伤害加成等）。
  见 `data/characters/characters.csv` 的 `ascension_stat` / `ascension_stat_value` 两列。

### 3.2 稀有度与成长

| 稀有度 | 等级上限 | 突破次数 | 说明 |
|---|---|---|---|
| 5★ | 90 | 6 | |
| 4★ | 90 | 6 | 基础值整体低于 5★ |
| 3★ / 2★ / 1★ | 70 / 70 / 70 | 4 | 仅武器 |

### 4.1 圣遗物主词条（5★ 满级 +20）

| 空之杯 | 元素伤害加成% / 物理伤害加成% / 攻击力% / 生命值% / 防御力% / 元素精通 | `?` |
| 理之冠 | 暴击率% / 暴击伤害% / 攻击力% / 生命值% / 防御力% / 元素精通 / 治疗加成% | `?` |

> 待核实原因：不同词条的满级数值档位不同（如暴击率与暴击伤害的档位不同），
> 必须逐条对照游戏内数值录入，不得套用统一比例。

### 4.2 副词条单次强化档位

副词条在获得与每次强化时，从若干**档位**中取值。具体档位表需核实后录入
`data/artifacts/artifact_substat_tiers.csv`（待建）。

### 4.3 词条价值比较方法

比较不同词条时使用**边际收益**而非名义数值：

```
某词条的边际收益 = 该词条提升后的期望伤害 / 原期望伤害 - 1
```

- 双爆词条：按 `1 + 暴击率 × 暴击伤害` 计算，需考虑**暴击率溢出**。
- 攻击力%：按 `面板攻击力` 的相对增幅计算，受**基础攻击力占比**影响。
- 元素精通：按反应公式计算，注意**递减**（见 [reactions.md](reactions.md#精通加成系数)）。
- 元素充能效率：**不直接提升伤害**，只有在「刚好满足循环需求」前才有价值；
  超出需求的部分收益为 0（详见 [energy-and-rotation.md](energy-and-rotation.md)）。

> 这套换算方法与词条优先级规则见 [`rules/stat-priority.md`](../../rules/stat-priority.md)（待补）。
