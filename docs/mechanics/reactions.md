## 1. 反应分类

| 类别 | 反应 | 伤害来源 | 计算公式 |
|---|---|---|---|
| **增幅反应** | 蒸发、融化 | 放大原本那次伤害 | [§2](#2-增幅反应) |
| **剧变反应** | 超载、感电、超导、碎冰、扩散、结晶、绽放、超绽放、烈绽放 | 反应自身独立伤害 | [§3](#3-剧变反应) |
| **无伤害反应** | 冻结、燃烧、原激化（仅生成状态） | 无直接伤害 | [§4](#4-无直接伤害的反应) |
| **催化反应** | 原激化 → 超激化 / 蔓激化 | 加到原本那次伤害的**基础伤害区** | [§4.2](#42-催化反应激化系列) |

关联键：元素用英文小写枚举 `pyro` `hydro` `anemo` `electro` `dendro` `cryo` `geo` `physical`。

## 2. 增幅反应

**蒸发（Vaporize）** 与 **融化（Melt）** 会放大触发它的那次伤害。

```
最终伤害 = 原伤害 × 反应倍率 × (1 + 2.78 × 元素精通 / (元素精通 + 1400))
```

### 反应倍率

| 反应 | 触发元素 → 已附着元素 | 反应倍率 |
|---|---|---|
| 蒸发 | `hydro` 打 `pyro` 附着 | **2.0** |
| 蒸发 | `pyro` 打 `hydro` 附着 | **1.5** |
| 融化 | `pyro` 打 `cryo` 附着 | **2.0** |
| 融化 | `cryo` 打 `pyro` 附着 | **1.5** |

记忆要点：**水打火 2 倍、火打水 1.5 倍；火打冰 2 倍、冰打火 1.5 倍。**

### 精通加成系数

```
元素精通加成 = 2.78 × EM / (EM + 1400)
```

| 元素精通 | 精通加成 | 2.0 倍反应总倍率 | 1.5 倍反应总倍率 |
|---|---|---|---|
| 0 | 0% | 2.000 | 1.500 |
| 100 | 18.5% | 2.371 | 1.778 |
| 200 | 34.8% | 2.695 | 2.021 |
| 400 | 61.8% | 3.235 | 2.426 |
| 800 | 100.0% | 4.000 | 3.000 |
| 1000 | 115.8% | 4.317 | 3.237 |

> ⚠️ 精通收益**递减明显**。0 → 100 精通收益 18.5%，800 → 1000 收益仅 7.9%。

### 关键性质

- 增幅反应**吃**：暴击、伤害加成区、防御区、抗性区、触发者的精通。
- 增幅反应倍率**只与触发者（造成伤害的角色）的精通有关**，与附着者无关。
- 因此配队中「谁触发反应」直接决定该堆谁的精通。

## 3. 剧变反应

剧变反应产生**独立于技能倍率的伤害**，有自己的一套公式。

```
剧变反应伤害 = 反应基础伤害
             × (1 + 2.78 × 元素精通 / (元素精通 + 1400))
             × 抗性区
             × 反应伤害加成区（若有，如「如雷的盛怒」4 件套）
```

```
反应基础伤害 = 等级系数(角色等级) × 反应倍率
```

### 关键性质

| 性质 | 剧变反应 | 说明 |
|---|---|---|
| 吃暴击？ | ❌ 否 | 不暴击 |
| 吃伤害加成？ | ❌ 否 | 元素伤害加成、类型伤害加成均无效 |
| 吃防御区？ | ❌ 否 | 与敌人等级防御无关 |
| 吃抗性区？ | ✅ 是 | 按反应对应元素的抗性计算 |
| 吃元素精通？ | ✅ 是 | 触发者精通 |
| 受等级影响？ | ✅ 是 | 通过等级系数，**角色等级必须拉满** |

> 结论：剧变反应队的角色等级优先级极高，且不需要堆暴击词条。

### 系数表状态

⚠️ **本仓库尚未收录并核实剧变反应的等级系数与各反应倍率数值。**

需核实的项（在 `data/elements/reactions.csv` 中以 `?` 标记）：

- 各反应倍率（超载 / 感电 / 超导 / 碎冰 / 扩散 / 结晶 / 绽放系各不相同）
- 角色等级 → 等级系数 的换算表
- 各反应的附着量消耗（见 [aura-icd.md](aura-icd.md)）
- 超绽放 / 烈绽放 / 原激化 系（草元素）的触发者判定与系数

> AI 使用要求：在数值补齐前，**不得给出剧变反应的具体伤害数字**，
> 只能给出公式结构与相对关系（例如「超载倍率高于超导」这类方向性判断也需有出处）。

## 4. 无直接伤害的反应

### 4.1 冻结与燃烧

| 反应 | 效果 | 备注 |
|---|---|---|
| 冻结（Frozen） | `cryo` + `hydro` → 冻结状态，敌人无法行动 | 自身无伤害；碎冰可解除并造成物理伤害 |
| 燃烧（Burning） | `pyro` + `dendro` → 持续火元素伤害 | 属持续伤害（DoT），按 pyro 抗性结算 |
| 结晶（Crystallize） | `geo` + 其他元素 → 生成晶片，拾取得护盾 | 护盾量吃元素精通 |

### 4.2 催化反应（激化系列）

草元素相关的**激化系**不是独立的剧变伤害，而是**加到原伤害的基础伤害区**：

| 反应 | 触发 | 效果 |
|---|---|---|
| 原激化（Quicken） | `dendro` + `electro` | 生成「激化」状态（本身无伤害） |
| 超激化（Aggravate） | 对激化状态敌人造成 `electro` 伤害 | 基础伤害增加 |
| 蔓激化（Spread） | 对激化状态敌人造成 `dendro` 伤害 | 基础伤害增加 |

因为加进**基础伤害区**，所以催化反应：

- ✅ 吃暴击、吃伤害加成区、吃防御区、吃抗性区
- ✅ 吃元素精通（通过基础伤害增加值）
- ⚠️ 与增幅反应的区别：作用于「基础伤害」而非「最终伤害」，因此**不与其他乘区相乘叠加**

```
激化后基础伤害 = 技能倍率 × 面板属性 + 激化增加值(等级系数 × 精通系数)
```

> 等级系数与精通系数的具体数值同样**待核实**，见 `data/elements/reactions.csv`。

### 4.3 绽放系（草元素剧变）

| 反应 | 组合 | 产物 | 伤害归属 |
|---|---|---|---|
| 绽放（Bloom） | `dendro` + `hydro` | 草原核，延迟爆炸 | 草原核爆炸，草元素伤害 |
| 超绽放（Hyperbloom） | 草原核 + `electro` | 追踪弹 | 雷元素伤害，取**触发者**精通 |
| 烈绽放（Burgeon） | 草原核 + `pyro` | 范围爆炸 | 火元素伤害，取**触发者**精通，会伤及自身 |

- 草原核有生成上限，超出会提前引爆。
- 超绽放 / 烈绽放的伤害**取决于引爆它的角色**的精通与等级，而非产核者。

## 5. 元素附着与反应触发

反应能否触发取决于**元素附着量**，而非单纯「元素碰到元素」。
详细规则见 [aura-icd.md](aura-icd.md)。

要点：

- 攻击必须带有**元素附着**才可能触发反应；部分攻击只造成伤害不附着，不会触发反应。
- 反应消耗附着量，附着量耗尽后残留元素消失。
- 同一攻击序列受 **ICD（内部冷却）** 限制，并非每次命中都附着。
