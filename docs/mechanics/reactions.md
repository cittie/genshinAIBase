## 1. 反应分类

| 类别 | 反应 | 伤害来源 | 计算公式 |
|---|---|---|---|
| **增幅反应** | 蒸发、融化 | 放大原本那次伤害 | [§2](#2-增幅反应) |
| **剧变反应** | 超载、感电、超导、碎冰、扩散、结晶、**燃烧**、绽放、超绽放、烈绽放 | 反应自身独立伤害 | [§3](#3-剧变反应) |
| **催化反应** | 原激化 → 超激化 / 蔓激化 | 加到原本那次伤害的**基础伤害区** | [§4.2](#42-催化反应激化系列) |
| **无伤害反应** | 冻结、原激化（仅生成状态） | 无直接伤害 | [§4.1](#41-冻结) |

> 注意：**燃烧是剧变反应**（有 0.25 倍率、造成火伤），不是「无伤害反应」；
> **结晶虽属剧变但同样不造成伤害**，其护盾量吃等级与精通。

关联键：元素用英文小写枚举 `pyro` `hydro` `anemo` `electro` `dendro` `cryo` `geo` `physical`。

### 精通加成系数：**三种反应各不相同**

| 反应类别 | 精通加成系数 | 备注 |
|---|---|---|
| 增幅（蒸发/融化） | `2.78 × EM / (1400 + EM)` | 乘在**最终伤害**上 |
| 剧变（超载/感电/超导/碎冰/扩散/燃烧/绽放系） | `16 × EM / (2000 + EM)` | 乘在**反应基础伤害**上；收益远高于增幅 |
| 催化（超激化/蔓激化） | `5 × EM / (1200 + EM)` | 加到**基础伤害区** |

> ⚠️ 常见错误：把增幅的 `2.78/(1400+EM)` 套到剧变上。两者差距极大——
> 1000 精通时剧变加成 **+533%**，而按增幅公式只有 +116%。

## 2. 增幅反应

**蒸发（Vaporize）** 与 **融化（Melt）** 会放大触发它的那次伤害。

```
最终伤害 = 原伤害 × 反应倍率 × (1 + 2.78 × 元素精通 / (元素精通 + 1400))
```

### 反应倍率

| 反应 | 触发元素 → 已附着元素 | 反应倍率 |
|---|---|---|
| 蒸发 | `hydro` 打 `pyro` 附着 | **2.0** |
| 蒸发 | `pyro` 打 `hydro` 附着 | **1.5** |
| 融化 | `pyro` 打 `cryo` 附着 | **2.0** |
| 融化 | `cryo` 打 `pyro` 附着 | **1.5** |

记忆要点：**水打火 2 倍、火打水 1.5 倍；火打冰 2 倍、冰打火 1.5 倍。**

### 精通加成系数

```
元素精通加成 = 2.78 × EM / (EM + 1400)
```

| 元素精通 | 精通加成 | 2.0 倍反应总倍率 | 1.5 倍反应总倍率 |
|---|---|---|---|
| 0 | 0% | 2.000 | 1.500 |
| 100 | 18.5% | 2.371 | 1.778 |
| 200 | 34.8% | 2.695 | 2.021 |
| 400 | 61.8% | 3.235 | 2.426 |
| 800 | 100.0% | 4.000 | 3.000 |
| 1000 | 115.8% | 4.317 | 3.237 |

> ⚠️ 精通收益**递减明显**。0 → 100 精通收益 18.5%，800 → 1000 收益仅 7.9%。

### 关键性质

- 增幅反应**吃**：暴击、伤害加成区、防御区、抗性区、触发者的精通。
- 增幅反应倍率**只与触发者（造成伤害的角色）的精通有关**，与附着者无关。
- 因此配队中「谁触发反应」直接决定该堆谁的精通。

## 3. 剧变反应

剧变反应产生**独立于技能倍率的伤害**，有自己的一套公式。

```
剧变反应伤害 = 反应倍率 × 等级系数(角色等级)
             × (1 + 16 × 元素精通 / (元素精通 + 2000) + 反应伤害加成)
             × 抗性区
```

> 注意：**没有防御区**（与敌人等级无关），**不吃暴击与元素伤害加成**。

### 关键性质

| 性质 | 剧变反应 | 说明 |
|---|---|---|
| 吃暴击？ | ❌ 否 | 不暴击（纳西妲 2 命可使绽放系暴击，属例外） |
| 吃伤害加成？ | ❌ 否 | 元素伤害加成、类型伤害加成均无效 |
| 吃防御区？ | ❌ 否 | 与敌人等级防御无关 |
| 吃抗性区？ | ✅ 是 | 按反应对应元素的抗性计算 |
| 吃元素精通？ | ✅ 是 | 触发者精通 |
| 受等级影响？ | ✅ 是 | 通过等级系数，**角色等级必须拉满** |

> 结论：剧变反应队的角色等级优先级极高，且不需要堆暴击词条。
> 剧变伤害**只吃精通与等级**，因此触发者是谁直接决定该堆谁的精通。

### 反应倍率（v7.1，已过 5.2 加强）

| 反应 | 倍率 | 伤害元素 | 备注 |
|---|---|---|---|
| 烈绽放 / 超绽放 / 碎冰 | **3** | 草 / 草 / 物理 | |
| 超载 | **2.75** | 火 | 反应内建 ICD 0.5 秒 |
| 感电 | **2 × 触发次数** | 雷 | 每秒一跳 |
| 绽放（草原核爆炸） | **2** | 草 | 绽放本身不造成伤害 |
| 超导 | **1.5** | 冰 | 使敌人**物理抗性降低 40%**、持续 12 秒 |
| 扩散 | **0.6** | 被扩散的元素 | 伤害取触发扩散者的等级与精通 |
| 燃烧 | **0.25** | 火 | 每 0.25 秒一跳 |
| 结晶 | **0** | 无 | 不造成伤害，护盾量吃等级与精通 |
| 激化扩散 | **0.6** | 雷 | 虽由激化引发，仍按剧变反应计算 |

> ⚠️ 旧攻略常见值（超载 2.0、超导 0.5、碎冰 1.5、感电 1.2）**均为 5.2 之前的数值**。

## 4. 其余反应

### 4.1 冻结

| 反应 | 效果 | 备注 |
|---|---|---|
| 冻结（Frozen） | `cryo` + `hydro` → 冻结状态，敌人无法行动 | 自身**无伤害**；碎冰可解除并造成物理伤害 |

冻结的时长由**冻结附着量**决定：

```
冻结附着量 = 2 × min(原附着量, 触发附着量)
冻结时长(秒) = 2 × √(5 × 冻结附着量 × (1 − 冻结抗性) + 4) − 4
```

> 连续冻结会因「冻结→解冻」的时间差而缩短（`Decay Time Modifier`），
> 完整公式见 [`aura-icd.md`](aura-icd.md)。部分敌人有冻结抗性，只影响时长、不影响冻结附着量。

### 4.2 催化反应（激化系列）

草元素相关的**激化系**不是独立的剧变伤害，而是**加到原伤害的基础伤害区**：

| 反应 | 触发 | 效果 | 反应倍率 |
|---|---|---|---|
| 原激化（Quicken） | `dendro` + `electro` | 生成「激化」状态（本身无伤害） | — |
| 超激化（Aggravate） | 对激化状态敌人造成 `electro` 伤害 | 基础伤害增加 | **1.15** |
| 蔓激化（Spread） | 对激化状态敌人造成 `dendro` 伤害 | 基础伤害增加 | **1.25** |

因为加进**基础伤害区**，所以催化反应：

- ✅ 吃暴击、吃伤害加成区、吃防御区、吃抗性区
- ✅ 吃元素精通（通过基础伤害增加值）
- ⚠️ 与增幅反应的区别：作用于「基础伤害」而非「最终伤害」，因此**不与其他乘区相乘叠加**

```
激化增加值 = 反应倍率 × 等级系数(角色等级) × (1 + 5 × EM / (1200 + EM) + 反应加成)
激化后基础伤害 = 技能倍率 × 面板属性 + 激化增加值
```

> 注意催化反应**用剧变的等级系数**（同 `level_coefficients.csv` 的 `player_multiplier`），
> 但精通系数是 `5/(1200+EM)`，与剧变的 `16/(2000+EM)` 不同。

### 4.3 绽放系（草元素剧变）

| 反应 | 组合 | 产物 | 伤害元素与归属 |
|---|---|---|---|
| 绽放（Bloom） | `dendro` + `hydro` | 草原核（本身无伤害） | 草原核爆炸时为**草元素伤害** |
| 超绽放（Hyperbloom） | 草原核 + `electro` | 追踪弹 | **草元素伤害**，取**雷触发者**的等级与精通 |
| 烈绽放（Burgeon） | 草原核 + `pyro` | 范围爆炸 | **草元素伤害**，取**火触发者**的等级与精通 |

> ⚠️ 常见错误：超绽放 / 烈绽放的伤害**都是草元素**，不是雷/火元素。
> 因此**堆草元素抗性削减（如深林 4 件套）能提升它们**，而雷/火抗削减不能。

- 草原核 6 秒后自动爆炸；场上已有 5 个时再触发绽放会立刻引爆第 1 个。
- 超绽放 / 烈绽放的伤害**取决于引爆它的角色**的精通与等级，而非产核者。
- 三者共享 ICD：每 0.5 秒最多 2 次伤害（每个敌人）；均**不附着草元素**。
- 烈绽放会伤及自身，但对玩家的伤害减少 95%，且只受玩家自身草抗影响。

## 5. 元素附着与反应触发

反应能否触发取决于**元素附着量**，而非单纯「元素碰到元素」。
详细规则见 [aura-icd.md](aura-icd.md)。

要点：

- 攻击必须带有**元素附着**才可能触发反应；部分攻击只造成伤害不附着，不会触发反应。
- 反应消耗附着量，附着量耗尽后残留元素消失。
- 同一攻击序列受 **ICD（内部冷却）** 限制，并非每次命中都附着。
