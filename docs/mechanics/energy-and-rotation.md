# 元素能量与输出循环

> 元素爆发的能量需求如何满足、微粒/晶球如何结算、循环轴怎么建立。
> 机读数值：[`data/elements/particle_energy.csv`](../../data/elements/particle_energy.csv)
> 来源：KQM Theorycrafting Library（固定 commit `106c0f3`），Energy。

---

## 1. 能量回复的三种来源

| 来源 | 说明 | 是否受元素充能效率影响 |
|---|---|---|
| **元素微粒 / 元素晶球** | 角色技能命中敌人时产生，需被角色拾取 | ✅ 是 |
| **固定回能** | 天赋/命座/武器被动的「恢复 X 点元素能量」 | ❌ 否 |
| **普攻命中回能** | 普攻/重击命中时有概率给**在场角色**约 1 点固定回能 | ❌ 否 |

> **关键区分**：只有**微粒/晶球**受元素充能效率（ER%）加成。
> 描述为「恢复 X 点元素能量」的效果是**固定值**，堆充能效率无效。
> 普攻回能同样只有**在场角色**能获得，后台角色拿不到，且不受 ER% 影响。

---

## 2. 微粒与晶球结算规则

元素能量在角色拾取微粒/晶球时结算，结算量取决于四个因素：

1. **拾取物类型**：元素微粒 vs 元素晶球（晶球为微粒的 **3 倍**）
2. **元素是否匹配**：与拾取者元素相同（**3 倍**）/ 不同（基准）/ 无色（**2 倍**）
3. **拾取者是否在场**：在场角色获得全额，后台角色打折
4. **队伍人数**（仅影响后台系数）：4 人 **60%** / 3 人 **70%** / 2 人 **80%**

### 基础能量表

| 拾取者位置 | 队伍人数 | 元素关系 | 元素微粒 | 元素晶球 |
|---|---|---|---|---|
| 在场 | — | 同元素 | **3.0** | **9.0** |
| 在场 | — | 异元素 | **1.0** | **3.0** |
| 在场 | — | 无色 | **2.0** | **6.0** |
| 后台 | 4 人 | 同元素 | 1.8 | 5.4 |
| 后台 | 4 人 | 异元素 | 0.6 | 1.8 |
| 后台 | 4 人 | 无色 | 1.2 | 3.6 |
| 后台 | 3 人 | 同元素 | 2.1 | 6.3 |
| 后台 | 3 人 | 异元素 | 0.7 | 2.1 |
| 后台 | 3 人 | 无色 | 1.4 | 4.2 |
| 后台 | 2 人 | 同元素 | 2.4 | 7.2 |
| 后台 | 2 人 | 异元素 | 0.8 | 2.4 |
| 后台 | 2 人 | 无色 | 1.6 | 4.8 |

```
实际获得能量 = 基础能量(上表) × (元素充能效率 / 100)
```

> ⚠️ **「后台系数」是本表最易错的地方**：它不是固定的 80%，
> 而是随队伍人数变化（4 人 60% 最苛刻）。满编四人队时后台角色的回能效率最低。
> 上表已把后台系数并入，直接查表即可，无需再乘。

### 需要注意的性质

- 微粒/晶球产自**谁**与**给谁回能**是两回事：产球角色的元素决定「同/异元素」判定，
  与拾取者的元素比较。
- 多个角色同时在场时，同一微粒只被**一个**角色拾取结算。
- 产球有**内置冷却**，并非每次命中都产球。
- 击杀敌人、部分环境物、部分天赋也会产球。
- 部分角色的元素战技**不产球**（如芭芭拉、诺艾尔）。
- 西风系列武器触发时产生 **3 个无色微粒**（受 ER% 影响；精炼只影响触发频率，不影响数量）。
- 金珀·璞鸢、桂木斩长正、喜多院十文字等武器给的是**固定回能**，只有**装备者自己**获得。
- 学士 4 件套与流放者 4 件套给的是**固定回能**。

## 3. 元素充能效率需求

核心不等式：

```
一次循环内的总回能 ≥ 元素爆发能量需求
```

```
总回能 = Σ(各次拾取的能量) + Σ(固定回能)
```

由该式反解出所需 **ER%（元素充能效率）**：

```
所需 ER% = 100 × (爆发能量需求 - 固定回能) / (循环内微粒折算能量)
```

### 影响 ER 需求的因素

| 因素 | 影响方向 |
|---|---|
| 同元素队友数量 | 同元素队友越多，同元素微粒越多 → ER 需求越低 |
| 是否带「聚能」角色（产球型） | 显著降低全队 ER 需求 |
| 输出轴时长 | 轴越长，拾取机会越多 → ER 需求越低 |
| 站场时间 | 站场越久越容易拾取到自己产的球 |
| 武器/套装回能 | 固定回能可替代部分 ER |
| 命座 | 部分命座提供直接回能 |

> ⚠️ **ER 是「够用即止」属性**：超出循环需求的 ER 收益为 **0**。
> 因此评估圣遗物/武器时，必须先确定 ER 需求阈值，再评估溢出。

## 4. 输出循环（Rotation）建模

配队与配装比较必须建立在**明确的循环轴**上，否则结论不可比。

### 4.1 循环轴应记录的信息

| 项 | 说明 |
|---|---|
| 技能顺序 | 谁先放什么，精确到元素战技/爆发 |
| 各段耗时 | 秒（`_sec`） |
| 站场角色与时长 | 决定谁拾取微粒 |
| 循环总时长 | 秒 |
| 各角色所需 ER | 在该轴下刚好满足 |

### 4.2 常见循环结构

| 类型 | 特征 | ER 需求 |
|---|---|---|
| 前台主 C 站场 | 主 C 吃球多 | 主 C 低，后台辅助高 |
| 双击发（如双水双雷） | 同元素互充 | 整体偏低 |
| 单核队 | 辅助各自独立充能 | 整体偏高 |
| 快切（Quick Swap） | 频繁切换，每人都短暂站场 | 依赖产球与固定回能 |

## 5. 与其他机制的关系

- **剧变反应队**：需要角色等级拉满，但对 ER 的需求同样刚性（技能要放得出来）。
- **元素共鸣**：双雷共鸣提供额外回能与产球，直接影响 ER 需求计算。
- **武器选择**：充能类武器（如「祭礼」「西风」系）的价值取决于 ER 缺口，
  而非绝对数值。见 [`rules/weapon-selection.md`](../../rules/weapon-selection.md)。

## 6. 数据缺失说明

本仓库**尚未收录**：

- 各角色元素爆发能量需求（建议在 `data/characters/characters.csv` 增列 `burst_cost`）
- 各角色元素战技产球数量与冷却
- 微粒/晶球基础能量表（`data/elements/particle_energy.csv` 数值为空）

> AI 使用要求：缺失项必须声明「本仓库未收录」，不得给出具体 ER 百分比的精确建议；
> 只能给出方向性判断（「同元素队友越多，ER 需求越低」）。
