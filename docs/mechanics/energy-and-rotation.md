# 元素能量与输出循环

> 元素爆发的能量需求如何满足、微粒/晶球如何结算、循环轴怎么建立。
> 机读数值：[`data/elements/particle_energy.csv`](../../data/elements/particle_energy.csv)（表头已建，数值待核实）

---

## 1. 能量回复的三种来源

| 来源 | 说明 | 是否受元素充能效率影响 |
|---|---|---|
| **元素微粒 / 元素晶球** | 角色技能命中敌人时产生，需被角色拾取 | ✅ 是 |
| **固定回能** | 天赋/命座/武器被动的「恢复 X 点元素能量」 | ❌ 否 |
| **元素爆发命中回能** | 部分角色大招命中后自身回能 | ❌ 否 |

> **关键区分**：只有**微粒/晶球**受元素充能效率（ER%）加成。
> 描述为「恢复 X 点元素能量」的效果是**固定值**，堆充能效率无效。

---

## 2. 微粒与晶球结算规则

元素能量在角色拾取微粒/晶球时结算，结算量取决于三个因素：

1. **拾取物类型**：元素微粒 vs 元素晶球（晶球能量约为微粒的 3 倍）
2. **元素是否匹配**：与拾取者元素相同 / 不同 / 无色
3. **拾取者是否在场**：在场角色获得全额，**后台角色获得打折**（常见说法为 80%，需核实）

```
实际获得能量 = 基础能量 × 后台系数(若在后台) × (元素充能效率 / 100)
```

⚠️ **数值待核实**：上表中的基础能量与后台系数属于易错项，本仓库
`data/elements/particle_energy.csv` 已建表头但**数值留空**。
在补齐前，AI **不得给出具体能量数值**。

### 需要注意的性质

- 微粒/晶球产自**谁**与**给谁回能**是两回事：产球角色的元素决定「同/异元素」判定，
  与拾取者的元素比较。
- 多个角色同时在场时，同一微粒只被**一个**角色拾取结算。
- 产球有**内置冷却**，并非每次命中都产球。
- 击杀敌人、部分环境物、部分天赋也会产球。

## 3. 元素充能效率需求

核心不等式：

```
一次循环内的总回能 ≥ 元素爆发能量需求
```

```
总回能 = Σ(各次拾取的能量) + Σ(固定回能)
```

由该式反解出所需 **ER%（元素充能效率）**：

```
所需 ER% = 100 × (爆发能量需求 - 固定回能) / (循环内微粒折算能量)
```

### 影响 ER 需求的因素

| 因素 | 影响方向 |
|---|---|
| 同元素队友数量 | 同元素队友越多，同元素微粒越多 → ER 需求越低 |
| 是否带「聚能」角色（产球型） | 显著降低全队 ER 需求 |
| 输出轴时长 | 轴越长，拾取机会越多 → ER 需求越低 |
| 站场时间 | 站场越久越容易拾取到自己产的球 |
| 武器/套装回能 | 固定回能可替代部分 ER |
| 命座 | 部分命座提供直接回能 |

> ⚠️ **ER 是「够用即止」属性**：超出循环需求的 ER 收益为 **0**。
> 因此评估圣遗物/武器时，必须先确定 ER 需求阈值，再评估溢出。

## 4. 输出循环（Rotation）建模

配队与配装比较必须建立在**明确的循环轴**上，否则结论不可比。

### 4.1 循环轴应记录的信息

| 项 | 说明 |
|---|---|
| 技能顺序 | 谁先放什么，精确到元素战技/爆发 |
| 各段耗时 | 秒（`_sec`） |
| 站场角色与时长 | 决定谁拾取微粒 |
| 循环总时长 | 秒 |
| 各角色所需 ER | 在该轴下刚好满足 |

### 4.2 常见循环结构

| 类型 | 特征 | ER 需求 |
|---|---|---|
| 前台主 C 站场 | 主 C 吃球多 | 主 C 低，后台辅助高 |
| 双击发（如双水双雷） | 同元素互充 | 整体偏低 |
| 单核队 | 辅助各自独立充能 | 整体偏高 |
| 快切（Quick Swap） | 频繁切换，每人都短暂站场 | 依赖产球与固定回能 |

## 5. 与其他机制的关系

- **剧变反应队**：需要角色等级拉满，但对 ER 的需求同样刚性（技能要放得出来）。
- **元素共鸣**：双雷共鸣提供额外回能与产球，直接影响 ER 需求计算。
- **武器选择**：充能类武器（如「祭礼」「西风」系）的价值取决于 ER 缺口，
  而非绝对数值。见 [`rules/weapon-selection.md`](../../rules/weapon-selection.md)。

## 6. 数据缺失说明

本仓库**尚未收录**：

- 各角色元素爆发能量需求（建议在 `data/characters/characters.csv` 增列 `burst_cost`）
- 各角色元素战技产球数量与冷却
- 微粒/晶球基础能量表（`data/elements/particle_energy.csv` 数值为空）

> AI 使用要求：缺失项必须声明「本仓库未收录」，不得给出具体 ER 百分比的精确建议；
> 只能给出方向性判断（「同元素队友越多，ER 需求越低」）。
