# 词条优先级判定规则

> 输入：角色定位、伤害来源、队伍构成、ER 缺口
> 输出：该角色的**有效词条排序**
> 这是圣遗物与武器评估的共同地基。

---

## 1. 判定四问

对任意角色，依次回答四个问题，即可确定有效词条：

| # | 问题 | 影响 |
|---|---|---|
| Q1 | 伤害的**面板属性来源**是什么？攻击力 / 生命值 / 防御力 | 决定百分比词条的归属 |
| Q2 | 伤害的**类型来源**是什么？普攻 / 重击 / 元素战技 / 元素爆发 / 剧变反应 | 决定伤害加成类词条是否有效 |
| Q3 | 伤害是否**暴击**？ | 剧变反应队双爆无效 |
| Q4 | 伤害是否**吃元素精通**？反应触发者是谁？ | 决定精通是否是有效词条 |

补充问题：

| # | 问题 | 影响 |
|---|---|---|
| Q5 | ER 缺口是否 > 0？ | 决定充能词条的优先级 |
| Q6 | 是否有**属性转化类**固有天赋/武器被动？ | 可能改写整个优先级（如把精通转为伤害加成） |

## 2. 词条有效性判定表

### 2.1 属性类

| 词条 | 何时有效 |
|---|---|
| 攻击力% / 固定攻击力 | Q1 = 攻击力 |
| 生命值% / 固定生命值 | Q1 = 生命值；或生存位需要治疗量 |
| 防御力% / 固定防御力 | Q1 = 防御力；或护盾量/生存 |
| 元素精通 | Q4 = 是（增幅触发者 / 剧变触发者 / 激化触发者） |
| 元素充能效率% | Q5 = 是（有缺口） |

### 2.2 双爆类

| 词条 | 何时有效 |
|---|---|
| 暴击率% / 暴击伤害% | **Q3 = 是**（非剧变反应主导的伤害） |

**判定要点**：

- 伤害构成中**剧变反应占比高**（超绽放/烈绽放/超载主伤队）→ 双爆**几乎无效**。
- 增幅反应、激化反应、直接技能伤害 → 双爆**有效**。
- 治疗/护盾角色的治疗量与护盾量**不暴击** → 双爆无效。

### 2.3 伤害加成类

| 词条 | 何时有效 |
|---|---|
| 元素伤害加成%（对应元素） | 该元素伤害占比 > 0 |
| 物理伤害加成% | 物理伤害占比 > 0 |
| 普攻/重击/下落伤害加成% | 对应伤害类型占比可观 |
| 元素战技/爆发伤害加成% | 对应技能伤害占比可观 |
| 治疗加成% | 角色治疗量为队伍所需 |

> 判定「占比可观」：一般以该类型伤害占**总伤害 ≥ 20%** 作为纳入标准，
> 低于此值视为次要词条。

## 3. 词条排序生成流程

```
1. 按 §2 过滤掉无效词条
2. 对剩余词条，用边际收益公式计算单位词条的收益（见 docs/mechanics/stats-and-scaling.md §4.3）
3. 处理耦合关系：
   - 暴击率与暴击伤害按 1:2 平衡，单独提升任一项都会因失衡而降低收益
   - 暴击率超过 100% 后的部分收益为 0
   - ER 达到需求阈值后收益为 0
   - 元素精通收益递减（2.78×EM/(EM+1400)）
4. 输出排序与权重
```

### 耦合关系速查

| 情况 | 调整 |
|---|---|
| 暴击率 − 暴击伤害/2 > 20% | 暴击伤害词条优先 |
| 暴击伤害/2 − 暴击率 > 20% | 暴击率词条优先 |
| 暴击率接近/超过 100% | 暴击率词条价值归零 |
| ER 已达循环需求 | ER 词条价值归零 |
| 攻击力% 极高（如 > 200%） | 因同乘区稀释，双爆/精通相对更值钱 |
| 元素精通 > 800 | 精通收益显著递减，考虑转其他词条 |

## 4. 常见角色类型的词条模板

> 下列为**结构性模板**（方向性可靠），具体数值权重需按角色逐项核实。

| 角色类型 | 核心词条 | 次要词条 | 无效词条 |
|---|---|---|---|
| 攻击力主 C（技能伤害） | 暴击率 / 暴击伤害 | 攻击力%、对应伤害加成 | 防御力、治疗加成 |
| 生命值主 C | 暴击率 / 暴击伤害 | 生命值% | 攻击力% |
| 防御力主 C | 暴击率 / 暴击伤害 | 防御力% | 攻击力%、生命值% |
| 增幅反应触发者 | 元素精通、暴击率 / 暴击伤害 | 攻击力% | — |
| 剧变反应触发者 | 元素精通 | ER%、生存词条 | **双爆、伤害加成** |
| 纯治疗 | 生命值%（或攻击力%）、治疗加成 | ER% | 双爆 |
| 护盾 | 生命值%（或防御力%） | ER% | 双爆 |
| 增伤辅助 | 取决于其增伤是否吃自身属性 | ER%、生存词条 | 视情况 |
| 充能工具人 | ER% | 生存词条 | 双爆 |

## 5. 输出模板（强制）

```
【角色】xxx（slug）
【定位】main_dps / sub_dps / support / …
【判定】
  Q1 面板属性来源：攻击力
  Q2 伤害类型来源：元素爆发为主（约 xx%）+ 元素战技
  Q3 是否暴击：是
  Q4 是否吃精通：是（增幅反应触发者）
  Q5 ER 缺口：未知（数据未收录）
  Q6 属性转化天赋：无
【有效词条排序】
  1. 暴击伤害% / 暴击率%（保持约 1:2）
  2. 元素精通（作为增幅触发者）
  3. 攻击力%
  4. 元素充能效率%（仅至满足循环）
【无效词条】防御力%、治疗加成%
【前提】90 级 / 天赋 9-9-9 / 0 命 / 无专武
【数据缺口】…
```

## 6. 常见错误

| 错误 | 纠正 |
|---|---|
| 给剧变反应队推荐双爆 | 剧变反应不暴击，双爆无效 |
| 给治疗/护盾角色推荐双爆 | 治疗量与护盾量不暴击 |
| 无脑堆 ER | ER 超出需求后收益为 0 |
| 无脑堆元素精通 | 精通收益递减明显 |
| 忽略暴击率溢出 | 超过 100% 的暴击率无收益 |
| 忽略同乘区稀释 | 攻击力% 堆过高时，双爆与精通的相对价值上升 |
| 忽略属性转化天赋 | 可能使某个"废词条"变成核心词条 |
