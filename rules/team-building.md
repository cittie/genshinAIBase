# 配队规划规则

> 输入：主 C（或目标玩法）、场景、预算、可用角色池
> 输出：队伍构成 + 反应轴 + 职能缺口 + 替代方案
> 依赖：[`stat-priority.md`](stat-priority.md)、[`../docs/mechanics/reactions.md`](../docs/mechanics/reactions.md)

---

## 0. 先收集参数（缺失则追问或使用默认）

| 参数 | 取值 | 默认 |
|---|---|---|
| 目标场景 | 深境螺旋 / 幻想真境剧诗 / 大世界 / 单体 Boss / 群怪 | 深境螺旋 |
| 主 C | 角色 slug | 必填 |
| 角色池 | 可用的其他角色 | 必填 |
| 预算 | 五星命座 / 专武 / 仅四星 | 仅四星 + 0 命 |
| 玩家水平 | 手速 / 是否愿意练循环 | 中等 |
| 生存压力 | 是否需要护盾/治疗 | 需要 |

---

## 1. 职能模型（配队的基本骨架）

一支成熟的四人队通常需要覆盖以下职能。**职能 ≠ 角色**，一个角色可兼任多项。

| 职能 | `role` 枚举 | 是否必需 | 说明 |
|---|---|---|---|
| 主输出 | `main_dps` | ✅ 必需 | 站场或后台的核心伤害来源 |
| 后台输出 | `sub_dps` | 强烈建议 | 在切人期间持续造成伤害 |
| 增伤 / 减抗 | `buffer` / `debuffer` | 强烈建议 | 提升全队伤害或降低敌人抗性 |
| 生存 | `healer` / `shielder` | ✅ 必需 | 至少一种；高压环境优先护盾 |
| 充能 | `battery` | 视 ER 缺口 | ER 不足时必须补 |
| 元素附着 | `enabler` | 视反应需求 | 提供稳定的反应底料 |
| 聚怪 / 控制 | `crowd_control` | 群怪场景建议 | |

**判定顺序**：

```
1. 主 C 确定 → 2. 确定其伤害来源与有效词条 → 3. 反推需要的反应与底料元素
→ 4. 补齐增伤/减抗 → 5. 补齐生存 → 6. 检查 ER 缺口 → 7. 检查元素共鸣
```

---

## 2. 标准队伍模板

| 模板 | 结构 | 适用 |
|---|---|---|
| 单核站场 | 主 C（站场） + 副 C + 增伤 + 生存 | 常规输出队 |
| 双核 | 主 C + 副 C（均有可观伤害） + 增伤/生存 + 生存/充能 | 抗打断与容错更好 |
| 驾驶队 | 驾驶员（站场触发） + 3 名后台输出 | 后台角色伤害占比高时 |
| 反应队 | 主 C + 底料附着 + 副 C + 生存 | 蒸发/融化/绽放/超绽放 |
| 剧变队 | 触发者 + 稳定附着 + 增伤（精通类） + 生存 | 依赖剧变反应伤害 |
| 快切队 | 4 名短 CD 角色 | 高练度、手速要求高 |

## 3. 反应轴判定

对每一对「主 C 元素 / 队友元素」，判断能否形成**稳定反应轴**：

| 判定项 | 问题 |
|---|---|
| 反应类型 | 是增幅、剧变还是催化？（见 [reactions.md](../docs/mechanics/reactions.md)） |
| 触发者 | 反应由谁触发？**精通要堆在触发者身上** |
| 覆盖率 | 附着量与 ICD 是否支持稳定触发？（见 [aura-icd.md](../docs/mechanics/aura-icd.md)） |
| 反向污染 | 队友会不会抢走反应（如水中混入雷导致感电而非蒸发）？ |
| 反应自伤 | 烈绽放会伤及自身，需评估生存 |
| 元素共存 | 是否存在干扰性共存（如冻结干扰融化）？ |

**硬性判定**：

- 增幅队中，**反应倍率高的那一侧应作为触发者**（见 [reactions.md §2](../docs/mechanics/reactions.md#反应倍率)）。
- 若主 C 是蒸发队的**触发者**，则主 C 需要堆元素精通；若主 C 只是提供底料，则不需要。
- 剧变反应队**不堆暴击**，词条转向元素精通、元素充能效率与生存。

---

## 4. 元素共鸣判定

队伍中同元素角色达到 2 人时触发元素共鸣。各共鸣的**增益方向**如下：

| 共鸣 | 触发条件 | 增益方向 | 具体数值 |
|---|---|---|---|
| 双火 | 2 名 `pyro` | 攻击力类增益 | 待核实 |
| 双水 | 2 名 `hydro` | 生命值 / 生存类增益 | 待核实 |
| 双雷 | 2 名 `electro` | 元素能量 / 充能类增益 | 待核实 |
| 双冰 | 2 名 `cryo` | 对特定状态敌人的暴击率增益 | 待核实 |
| 双风 | 2 名 `anemo` | 机动、冷却缩减类增益 | 待核实 |
| 双岩 | 2 名 `geo` | 护盾与岩元素伤害类增益 | 待核实 |
| 双草 | 2 名 `dendro` | 元素精通类增益 | 待核实 |

> ⚠️ **具体数值待核实**，占位表：[`../data/teams/elemental_resonance.csv`](../data/teams/elemental_resonance.csv)。
> 在补齐前，AI 只能说明「双 X 共鸣提供 Y 类增益」，**不得给出百分比数字**。

**判定原则（方向性，可靠）**：

- 双火/双水/双岩属于**属性增益**，直接提升输出或生存。
- 双雷属于**充能增益**，价值取决于 ER 缺口是否存在（缺口为 0 时收益为 0）。
- 双冰属于**暴击增益**，在有冻结或冰附着的队伍中收益最高。
- 双风属于**机动增益**，与伤害无关，仅在需要跑动或频繁切人的场景有价值。
- 双草/双水/双雷是**绽放系队伍的常见组合**。

> **不要为了共鸣而牺牲职能覆盖。** 缺生存时补生存位，比凑共鸣更重要。

## 5. 充能（ER）判定

```
对每个角色：
  ER 需求 = 100 × (爆发能量需求 - 固定回能) / 循环内该角色获得的微粒折算能量
```

判定流程：

1. 估算循环时长与各角色站场时间。
2. 统计产球角色的产球量与元素类型。
3. 计算各角色的 ER 缺口。
4. **缺口 > 0 的角色必须带充能手段**（充能沙 / 充能武器 / 充能队友 / 双雷共鸣）。

> ⚠️ 本仓库**尚未收录**产球与能量数值（见 [energy-and-rotation.md §6](../docs/mechanics/energy-and-rotation.md#6-数据缺失说明)）。
> 在补齐前，只能给出**方向性**判断：
> 「同元素队友越多 ER 需求越低」「带产球型角色可降低全队 ER 需求」「ER 超出需求后收益为 0」。

## 6. 场景适配

| 场景 | 关键约束 |
|---|---|
| 深境螺旋 | 双队伍、限时、怪物分批；重视**清怪速度**与**生存** |
| 幻想真境剧诗 | **元素限制 + 角色池限制**；需自备角色，重视**阵容广度**而非单队强度 |
| 大世界 | 移动、续航、操作便利；伤害要求低 |
| 单体 Boss | 重视单点爆发与**循环稳定性**（不依赖击杀产球） |
| 群怪 | 重视范围伤害与**聚怪** |

**剧诗配队要求**：优先保证「每个可用元素都有能打的角色」，而不是把资源全压在一支队伍上。

## 7. 输出模板（强制）

```
【队伍】队名（主 C + 队友1 + 队友2 + 队友3）

| 位置 | 角色 | 职能 | 关键作用 |
|---|---|---|---|
| 主 C | xxx | main_dps | … |
| 副 C | xxx | sub_dps | … |
| 增伤 | xxx | buffer | … |
| 生存 | xxx | shielder | … |

【反应轴】触发顺序与循环要点（谁先挂元素、谁触发反应）
【元素共鸣】触发了哪些，增益方向
【ER 检查】各角色是否需要充能手段（缺口未知时显式声明）
【优势】…
【职能缺口】…
【替代方案】每个位置至少一个下位替代及其代价
【前提】命座 / 武器 / 天赋等级 / 敌人假定
【数据缺口】本仓库未收录且影响结论的数值
```

## 8. 常见错误（禁止）

| 错误 | 纠正 |
|---|---|
| 只堆输出位，不带生存 | 除极熟练的大世界玩法外，生存位必需 |
| 为凑共鸣牺牲职能覆盖 | 职能优先于共鸣 |
| 忽略 ER 缺口 | ER 不足导致循环断裂，实际 DPS 大幅下降 |
| 精通堆错角色 | 精通只对**反应触发者**有意义 |
| 剧变队堆暴击 | 剧变反应不暴击，暴击词条无效 |
| 假设「每次伤害都触发反应」 | 必须考虑附着量与 ICD 导致的覆盖率损失 |
| 不声明命座/精炼前提 | 结论不可复现 |
