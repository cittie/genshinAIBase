# 圣遗物选择规则

> 输入：角色定位、有效词条、现有库存、套装获取成本
> 输出：套装方案 + 主词条 + 副词条优先级 + 毕业标准
> 依赖：[`stat-priority.md`](stat-priority.md)

---

## 0. 决策顺序（不可打乱）

```
1. 确定角色定位与有效词条        → rules/stat-priority.md
2. 决定套装结构（4件套 / 2+2 / 2+散件）
3. 决定主词条（沙 / 杯 / 头）
4. 决定副词条优先级
5. 评估库存质量（有效词条数）
6. 给出毕业标准与替代路径
```

**为什么顺序不能乱**：套装决定是否需要牺牲散件副词条；
主词条决定双爆能否配平；先选副词条会导致主词条选了错误的属性。

---

## 1. 套装结构判定

### 1.1 判定树

```
该角色是否存在「4 件套效果触发率高且收益显著」的套装？
├─ 是 → 4 件套
│        └─ 但若散件副词条远优于套装件（差距 ≥ 2 个有效词条/件）→ 可考虑 2+2 过渡
└─ 否 → 2 件套 + 2 件套（或 2 件套 + 3 散件，仅当散件极强）
```

### 1.2 4 件套 vs 2+2 的取舍

| 维度 | 4 件套 | 2+2 |
|---|---|---|
| 上限 | 更高（4 件套效果通常强于 2 件套叠加） | 略低 |
| 触发条件 | 可能需要特定操作/反应/站场 | 无条件常驻 |
| 词条自由度 | 低（必须凑 4 件） | 高（哪个部位副词条好用哪个） |
| 成型速度 | 慢 | 快 |

**判定要点**：

- 4 件套效果的**触发条件角色能否稳定满足**？不能稳定触发 → 果断 2+2。
- 若角色的 4 件套效果只在特定反应/操作下生效，而队伍不提供该条件 → 2+2 更优。
- **过渡期一律推荐 2+2**，或 4 件套但接受较差的副词条。

### 1.3 散件的使用

- 当 4 件套的某个部位长期刷不到好词条时，用**副词条极强的散件**替代该部位，
  代价是失去 4 件套效果 → 此时应改用 2+2。
- **不允许**「3 件套 + 2 散件」这种既失去 4 件套、又没凑成 2+2 的组合（除非 2 件套效果无用）。

## 2. 主词条判定

### 2.1 生之花 / 死之羽

主词条固定（生命值 / 攻击力），**无需决策**。选择只看套装与副词条。

### 2.2 时之沙

```
Q1 面板属性来源是什么？
├─ 攻击力 → 攻击力%（默认）
├─ 生命值 → 生命值%
└─ 防御力 → 防御力%

是否存在 ER 缺口？
└─ 是，且缺口大 → 元素充能效率%

该角色是否为反应触发者且精通收益高？
└─ 是 → 元素精通
```

判定优先级：**先保证循环（ER），再考虑输出（属性%/精通）**。

### 2.3 空之杯

```
该角色伤害是否以物理伤害为主？
├─ 是 → 物理伤害加成%
└─ 否 → 元素伤害加成%（对应元素）

存在例外（改用攻击力%）的情形：
- 该角色伤害元素不统一（多元素混伤）
- 已有大量同乘区加成导致稀释严重
- 该角色主要价值不是自身伤害（辅助/治疗）
```

> ⚠️ **稀释判定的量化**：当「伤害加成区」总额已经很高时（如套装 + 队友 buff 已提供大量加成），
> 攻击力% 的相对收益可能反超元素伤害加成%。需按
> [stats-and-scaling.md §4.3](../docs/mechanics/stats-and-scaling.md#43-词条价值比较方法) 实算，
> 不可凭感觉判断。

### 2.4 理之冠

```
该角色是否为治疗角色？
├─ 是 → 治疗加成% 或 生命值%（取决于治疗量是否吃生命值）
└─ 否 →
    该角色伤害是否暴击（非剧变主导）？
    ├─ 是 → 暴击率% 或 暴击伤害%（按 1:2 配比）
    └─ 否（剧变反应主导）→ 元素精通
```

**双爆配平规则**：

| 当前状态 | 选择 |
|---|---|
| 暴击率 < 暴击伤害 / 2 | 暴击率% |
| 暴击率 > 暴击伤害 / 2 | 暴击伤害% |
| 暴击率接近 100% | 暴击伤害%（暴击率已溢出） |

> 目标配比 `暴击率 : 暴击伤害 ≈ 1 : 2`。
> 通常最终目标约为暴击率 60~80% / 暴击伤害 120~160%（视武器与队友 buff 浮动）。

## 3. 副词条优先级

**直接引用** [`stat-priority.md`](stat-priority.md) 得出的有效词条排序。

通用规则：

1. **只关注有效词条**，无效词条按 0 计。
2. **固定值词条价值远低于百分比词条**（固定攻击力 / 固定防御力 / 固定生命值），
   除非角色基础值极低或该词条被天赋转化。
3. **元素充能效率是「够用即止」**：达到循环需求后，多余 ER 的收益为 0。
4. 副词条的价值要看**它强化了多少次**，而非「有没有出现」。

---

## 4. 库存质量评估：有效词条数

```
有效词条数 = Σ(每个副词条的强化次数 × 该词条是否有效)
```

| 有效词条数 | 评价 | 建议 |
|---|---|---|
| 5 | 接近毕业 | 保留 |
| 4 | 良好 | 可用，视资源决定是否继续刷 |
| 3 | 及格 | 过渡使用 |
| ≤ 2 | 较差 | 继续刷 |

**注意事项**：

- 计分时**必须**先确定该角色的有效词条集合（由 [stat-priority.md](stat-priority.md) 得出）。
- 同一件圣遗物对不同角色的评分不同，评估时要说清是**给谁**评估。
- 生之花与死之羽的主词条固定，因此这两件的副词条质量差异最容易拉开差距。

---

## 5. 毕业标准与替代路径

输出时必须给出**分层目标**：

| 层级 | 标准 | 适用 |
|---|---|---|
| 入门 | 主词条正确，套装结构达成 | 新角色刚拿到 |
| 及格 | 每件 ≥ 2~3 个有效词条 | 能打深渊 |
| 良好 | 每件 ≥ 4 个有效词条，双爆配平 | 主流水平 |
| 毕业 | 每件 ≈ 5 个有效词条 | 资源充裕 |

**替代路径**（至少给一条）：

- 用 2+2 替代 4 件套，代价是套装效果损失但副词条质量更高。
- 用「还圣奥迹」定向兑换稀缺部位。
- 优先提升**花与羽**（主词条固定，副词条是唯一变量，投入产出比高）。

## 6. 输出模板（强制）

```
【角色】xxx（slug）｜定位：main_dps
【有效词条】暴击伤害% > 暴击率% > 元素精通 > 攻击力%（依据 rules/stat-priority.md）
【套装方案】
  首选：4 件套「xxx」——触发条件：xxx，角色可稳定满足
  过渡：2 件套「xxx」+ 2 件套「xxx」
  备选：若 4 件套效果无法稳定触发，改用 2+2
【主词条】
  花：生命值（固定）｜羽：攻击力（固定）
  沙：xxx｜杯：xxx｜头：xxx
【副词条优先级】暴击伤害% / 暴击率% > 元素精通 > 攻击力%
【双爆目标】暴击率 ~xx% / 暴击伤害 ~xx%（保持 1:2）
【毕业标准】每件 4~5 个有效词条
【替代路径】…
【前提】90 级 / 天赋 9-9-9 / 0 命 / 敌人 90 级 10% 抗性
【数据缺口】套装数值、主词条满级数值未收录
```

## 7. 常见错误（禁止）

| 错误 | 纠正 |
|---|---|
| 不看角色定位就推荐套装 | 先定有效词条，再定套装 |
| 无脑推荐 4 件套 | 触发条件无法满足时 2+2 更优 |
| 给剧变反应队推荐双爆头 | 剧变不暴击，应选精通 |
| 给治疗角色推荐双爆 | 治疗量不暴击 |
| 只看主词条不看副词条 | 副词条才是强度差距的来源 |
| 忽略 ER 需求 | ER 不足会导致循环断裂 |
| 不说明「给谁评估」 | 同一件圣遗物对不同角色评分不同 |
| 编造套装数值 | 本仓库尚未收录，需显式声明 |
