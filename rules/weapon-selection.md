# 武器选择规则

> 输入：角色、武器类型、精炼等级、获取成本、ER 缺口
> 输出：分级武器推荐（专武 / 五星替代 / 四星最优 / 三星过渡）
> 依赖：[`stat-priority.md`](stat-priority.md)

---

## 0. 决策顺序（不可打乱）

```
1. 硬过滤：weapon_type 必须匹配
2. 确定角色的有效词条            → rules/stat-priority.md
3. 按「副属性适配度」排序
4. 检查被动触发条件
5. 检查基础攻击力与攻击力%收益的耦合
6. 检查 ER 缺口是否被填补
7. 按获取成本分层给出推荐
8. 声明精炼等级
```

---

## 1. 硬过滤

| 条件 | 说明 |
|---|---|
| `weapon_type` 匹配 | 角色只能装备对应类型的武器，**不可协商** |
| 稀有度可行 | 玩家实际能获取到的稀有度 |
| 精炼等级已知 | 必须明确 R1 还是 R5 |

> 过滤后若候选武器 < 3 把，说明角色池/预算信息不足，应追问而非硬答。

---

## 2. 评估维度与优先级

| 优先级 | 维度 | 说明 |
|---|---|---|
| 1 | **副属性适配** | 是否落在角色有效词条上（见 [stat-priority.md](stat-priority.md)） |
| 2 | **被动可触发性** | 角色能否稳定满足触发条件 |
| 3 | **充能缺口** | 是否填补或加剧 ER 缺口 |
| 4 | **基础攻击力** | 与攻击力%词条的收益耦合（见下） |
| 5 | **精炼成本** | 四星容易 R5，五星通常只能 R1 |
| 6 | **获取难度** | 限定池 / 常驻 / 锻造 / 活动 |

### 为什么副属性优先于基础攻击力

- 基础攻击力只影响**攻击力%词条的收益基数**，其贡献有限。
- 副属性是**独立乘区的词条**（如暴击伤害、元素精通），单位收益更高。
- ⚠️ **例外**：当角色的攻击力%词条总量很低、且不依赖双爆时，基础攻击力的相对重要性上升。

### 基础攻击力与攻击力%的耦合

```
攻击力% 的绝对收益 ∝ (角色基础攻击力 + 武器基础攻击力)
```

| 情况 | 结论 |
|---|---|
| 角色基础攻击力高 + 自身/队伍提供大量攻击力% | 高基础攻击力武器收益放大 |
| 角色基础攻击力低 + 不走攻击力流派（如生命/防御主 C） | 基础攻击力几乎无意义，副属性与被动决定一切 |
| 角色是纯辅助/治疗，不靠自身伤害 | 只关心副属性与被动，完全不看基础攻击力 |

> **重要**：生命值主 C（如以生命值计算伤害）与防御力主 C 不吃武器基础攻击力，
> 因此对这类角色，**四星专精武器常能超过五星高基础攻击力武器**。

---

## 3. 被动可触发性判定

| 判定项 | 问题 |
|---|---|
| 触发条件 | 普攻命中 / 重击 / 元素战技 / 元素爆发 / 触发反应 / 受击？ |
| 角色能否满足 | 该角色是否高频使用对应动作？ |
| 触发器频率 | 触发是否有 CD？角色能否卡准？ |
| 站场/后台 | 被动是否要求站场生效？后台角色装了就是白板 |
| 叠层机制 | 需要几层？能否快速叠满？ |
| 精炼依赖 | R1 与 R5 差距多大？ |

**典型陷阱**：

- 被动要求「重击命中」但角色几乎不用重击 → 被动等效不存在。
- 被动要求「站场」但角色是后台副 C → 完全无效。
- 被动在「击杀敌人后」生效 → 单体 Boss 战无效。
- 被动依赖「触发特定反应」但队伍不提供该反应 → 无效。

> **判定原则**：被动不可稳定触发时，该武器的实际价值 ≈ 只有副属性与基础攻击力的「白板武器」。

---

## 4. 充能缺口判定

```
该角色 ER 缺口 > 0？
├─ 是 → 优先考虑充能类武器，或接受较低伤害换循环稳定
└─ 否 → 充能类武器的充能部分收益为 0，只看其余部分
```

- 充能类武器的价值**完全取决于 ER 缺口**。
- ER 已满足时，充能副属性等效为「无效词条」，该武器降级为白板。
- 反之，若缺 ER，一把充能武器可能胜过专武（因为专武导致循环断裂）。

> ⚠️ 本仓库**尚未收录**产球/能量数值，无法计算精确 ER 缺口。
> 在补齐前必须声明「ER 缺口未量化」，并给出条件性建议：
> 「若循环中出现大招无法就绪，优先换充能武器」。

---

## 5. 推荐分层（强制四层）

输出时**必须**按获取成本分层，而不是只给一个「最优解」：

| 层级 | 说明 | 要求 |
|---|---|---|
| **专武** | 为该角色量身设计的五星武器 | 说明 R1 表现与是否值得抽 |
| **五星替代** | 其他五星武器 | 说明需要牺牲什么 |
| **四星最优** | 玩家最可能拥有的实用选择 | **必须给出**，通常按 R5 评估 |
| **三星过渡** | 新手期过渡 | 说明过渡到什么程度 |

**补充层级**（有则给）：锻造武器、活动限定武器、纪行武器。

---

## 6. 精炼等级的表述规则

| 规则 | 说明 |
|---|---|
| 必须声明 R 等级 | R1 与 R5 的被动数值可能相差数倍 |
| 四星默认按 R5 评估 | 四星容易满精 |
| 五星默认按 R1 评估 | 五星获取成本高 |
| 跨稀有度对比必须同精炼口径 | 否则结论无意义 |
| 精炼只影响被动 | 基础攻击力与副属性不随精炼变化 |

## 7. 输出模板（强制）

```
【角色】xxx（slug）｜武器类型：polearm
【有效词条】暴击伤害% > 暴击率% > 元素充能效率%（依据 rules/stat-priority.md）
【ER 缺口】未量化（数据缺）；若大招无法就绪，优先充能武器

【推荐分层】
| 层级 | 武器 | 精炼 | 适配理由 | 代价 |
|---|---|---|---|---|
| 专武 | xxx | R1 | 副属性为暴击伤害，被动常驻 | 需抽限定池 |
| 五星替代 | xxx | R1 | 副属性为攻击力%，被动易触发 | 双爆配平更难 |
| 四星最优 | xxx | R5 | 副属性为暴击率，被动要求普攻（角色高频普攻） | 基础攻击力偏低 |
| 三星过渡 | xxx | R5 | 提供充能，前期够用 | 上限低，中期换掉 |

【被动可触发性核查】…
【双爆配平影响】换武器后暴击率/暴击伤害目标如何调整
【替代方案】…
【前提】90 级 / 天赋 9-9-9 / 0 命 / 无队友 buff
【数据缺口】武器基础攻击力、副属性数值、被动文本均未收录
```

---

## 8. 常见错误（禁止）

| 错误 | 纠正 |
|---|---|
| 跨精炼等级对比 | 必须同精炼口径，或显式声明差异 |
| 只看基础攻击力 | 副属性与被动通常更重要 |
| 忽略被动触发条件 | 触发不了就是白板武器 |
| 给后台角色推荐站场被动武器 | 被动完全不生效 |
| 给生命/防御主 C 推荐高基础攻击力武器 | 这类角色不吃武器基础攻击力 |
| 只给一个「最优解」 | 必须分四层给替代 |
| 编造武器数值或排名 | 数值未收录时只能给方法论 |
| 忽略 ER 缺口 | 循环断裂时再高的伤害面板也无意义 |
