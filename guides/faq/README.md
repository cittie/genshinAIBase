# guides/faq/ — 常见问题

以问答形式收录高频问题，重点是**澄清易错概念**与**指向正确文件**。

---

## 命名规则

```
guides/faq/<topic>.md
```

建议主题：

| 文件名 | 主题 |
|---|---|
| `damage.md` | 伤害计算常见误解 |
| `artifacts.md` | 圣遗物词条与毕业 |
| `weapons.md` | 武器与精炼 |
| `energy.md` | 充能与循环 |
| `reactions.md` | 元素反应与附着 |
| `endgame.md` | 深渊与剧诗 |
| `glossary.md` | 黑话与缩写（指向 [`docs/glossary.md`](../../docs/glossary.md)） |

---

## 文件格式

```markdown
# 主题

## Q：问题原文（尽量用玩家的口语表述）

**A**：结论。

**依据**：[文件路径](相对路径)

**常见误解**：很多人以为……，实际上是……
```

要点：

1. **问题用口语**（含黑话），便于 AI 匹配用户提问。
2. **答案先给结论**，再给依据路径。
3. **必须写「常见误解」**：这正是 FAQ 的价值所在。
4. 涉及数值且本仓库未收录时，**明确声明未收录**。

---

## 与 docs/ 的分工

| | `docs/` | `guides/faq/` |
|---|---|---|
| 组织方式 | 按机制体系 | 按提问方式 |
| 风格 | 教科书式 | 问答式 |
| 目的 | 完整覆盖 | 快速纠错 |

> 若某个 FAQ 答案在 `docs/` 中已有完整说明，**只写结论 + 链接**，不要复制内容
> （避免两处内容不一致）。
